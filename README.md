# ELVIS.OS — Interactive Computational Portfolio World

> **The portfolio is a computational world that the visitor explores.**

`elvis-os` is a futuristic, atmospheric, and highly interactive digital universe built for Elvis Muchiri. Rather than presenting a traditional static resume, `elvis-os` places visitors inside an operating system environment where engineering, AI architecture, and project systems are spatial nodes.

---

## 🌟 Conceptual Regions

- **`IDENTITY` (`SYS.ID.01`)**: Engineering philosophy, background, core principles, and digital identity.
- **`SYSTEMS` (`SYS.ENG.02`)**: Full-stack engineering, backend architecture, reactive frontends, and cloud infrastructure.
- **`NEURAL CORE` (`SYS.AI.03`)**: AI/ML engineering, autonomous agents, RAG architecture, and vector embeddings.
- **`PROJECT LABS` (`SYS.LAB.04`)**: Major projects with interactive microservice mesh graph simulation (e.g., **Project Kijiji**).
- **`WORKSTATION` (`SYS.EXP.05`)**: Professional experience (including Vetted) and high-impact production achievements.
- **`ARCHIVE` (`SYS.DOC.06`)**: Direct CV documentation download, education, credentials, and career documentation.
- **`COMMUNICATION HUB` (`SYS.COM.07`)**: Direct channels, GitHub, LinkedIn, and email gateways.

---

## 🚀 Key Features & Interactions

- **System Boot Diagnostics**: Terminal initialization sequence (`INITIALIZING ELVIS.OS ... Loading neural architecture ... SYSTEM READY`) with skip capability.
- **3D Spatial World Canvas**: Built with Three.js featuring an ambient constellation grid, wireframe orbital nodes, energy connector beams, and smooth camera target interpolation.
- **Interactive Microservice Mesh Simulator**: Within `PROJECT LABS`, explore Project Kijiji's live microservice topology graph, inspecting downstream data pipes between API Gateways, Vector DBs, and Neural AI Routers.
- **Recruiter Fast Access**: Quick-access header bar for instant CV download and direct contact channels without puzzle solving.
- **Command Palette (`Cmd + K` or `/`)**: Rapid search across all computational regions and knowledge QA entries with an AI prompt query architecture.
- **Web Audio Ambient Synthesizer**: Optional low-frequency ambient drone and sound effects generated via Web Audio API.
- **Navigation Usability**: Press `[ESC]` anytime to return to the global world view.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Glassmorphic Dark Atmospheric Theme
- **3D Rendering**: Three.js (WebGL)
- **Icons**: Lucide React
- **Audio**: Native Web Audio API Synthesizer

## 💻 Local Setup Instructions

1. **Clone & Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```

## 🔮 Future Architecture Vision

`elvis-os` is architected with structured knowledge objects (`KnowledgeQA`) embedded in each region node. Future iterations can plug in an autonomous LLM agent layer allowing visitors to query:
- *"What did Elvis build at Vetted?"*
- *"Explain Project Kijiji's architecture."*
- *"Show me his AI/ML projects."*

The AI agent will directly route and navigate the 3D computational world in real-time based on query intent.
